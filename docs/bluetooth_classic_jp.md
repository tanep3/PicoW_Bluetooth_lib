# Bluetooth Classic の解説

[English](bluetooth_classic.md) | 日本語

この文書は Bluetooth Classic の一般的な仕組みを説明する背景資料です。ここに挙がるプロファイルすべてを本ライブラリが提供する意味ではありません。現在の対応範囲と使い方は [API リファレンス](api_reference_jp.md) と [検証範囲](validation_jp.md) を参照してください。HFP は非対応です。

## Bluetooth Classic とは？

Bluetooth Classic は、Bluetooth Basic Rate/Enhanced Data Rate (BR/EDR) とも呼ばれ、連続的な高スループットのデータストリーミングのために設計された Bluetooth 技術のオリジナルバージョンです。主に、以下のような、安定した接続と大量のデータ転送を必要とするアプリケーションで使用されます。

*   **ワイヤレスオーディオストリーミング (A2DP)**: ヘッドホン、スピーカー、カーオーディオシステムへの接続。
*   **音声通話 (HFP/HSP)**: 車内でのハンズフリー通話やヘッドセットでの通話。
*   **データ転送 (SPP)**: プリンターや古いモデムなどのデバイス向けのレガシーシリアルポートエミュレーション。
*   **ヒューマンインターフェースデバイス (HID)**: キーボード、マウス、ゲームコントローラーの接続（ただし、新しいHIDデバイスの多くは現在BLEを使用しています）。

### Bluetooth Classic の主な特徴:

*   **高いデータスループット**: Bluetooth Low Energy (BLE) と比較して、一般的に高いデータレート（最大3 Mbps）を提供します。
*   **ストリーミング機能**: 連続的なデータストリームに最適化されており、オーディオに理想的です。
*   **コネクション指向**: デバイス間で専用の永続的な接続を確立します。
*   **高い消費電力**: 連続的な接続と高いデータレートのため、BLEよりも多くの電力を消費する傾向があります。
*   **複雑なペアリング**: ペアリングプロセスは、PINコードや確認が必要な場合があり、より複雑になることがあります。

## Bluetooth Classic はどのように機能するのか？

Bluetooth Classic は2.4 GHz ISMバンドで動作し、周波数ホッピングスペクトラム拡散 (FHSS) と呼ばれる技術を使用しています。これは、干渉を回避し、セキュリティを強化するために、1秒間に何度も周波数を高速に切り替えることを意味します。

2つのBluetooth Classic デバイスが接続する場合:

1.  **Inquiry (問い合わせ)**: 他のデバイスを探しているデバイスは、問い合わせ信号を送信します。
2.  **Paging (ページング)**: デバイスが発見されると、イニシエーターは接続を確立するためにページング信号を送信します。
3.  **Connection (接続)**: 専用のリンクが確立され、デバイスはデータを交換できます。この接続は、両方のデバイスが範囲内にあり、電源が入っている限り維持されます。

## Bluetooth Classic と Bluetooth Low Energy (BLE) の比較

Bluetooth Classic と、Bluetooth 4.0 で導入された別の技術である Bluetooth Low Energy (BLE) を区別することが重要です。

| 特徴                | Bluetooth Classic (BR/EDR)                               | Bluetooth Low Energy (BLE)                               |
| :------------------ | :------------------------------------------------------- | :------------------------------------------------------- |
| **主な用途**        | 連続的なデータストリーミング（オーディオ、音声）         | 定期的なデータ転送（センサー、ウェアラブル、IoT）         |
| **データスループット** | 高い（最大3 Mbps）                                       | 低い（最大約2 Mbps、実際にはそれ以下の場合が多い）         |
| **消費電力**        | 高い                                                     | 非常に低い                                               |
| **接続タイプ**      | コネクション指向（永続的なリンク）                       | コネクション指向またはコネクションレス（短いバースト）     |
| **トポロジー**      | ポイントツーポイント、限定的なスキャッターネット         | ポイントツーポイント、ブロードキャスト、メッシュ         |
| **ペアリング**      | より複雑（PIN、パスキー）                                | よりシンプル（Just Works、パスキー、OOB）                |
| **検出**            | Inquiry/Paging                                           | Advertising/Scanning                                     |
| **プロファイル**    | A2DP、HFP、SPP、HID など                                 | GATTベースのプロファイル（例：心拍数プロファイル、近接プロファイル） |

## なぜ Bluetooth Classic は今でも重要なのか？

BLE の台頭にもかかわらず、Bluetooth Classic は、特にオーディオにおいて、高品質で連続的なデータストリームを必要とするアプリケーションにとって依然として重要です。例えば、ワイヤレスヘッドホンで音楽を聴いたり、車内でハンズフリー通話を行ったりすることは、大量の連続的なオーディオデータを確実に処理できる Bluetooth Classic の A2DP および HFP プロファイルに大きく依存しています。

Bluetooth Classic を理解することは、これらの確立されたプロファイルを使用するデバイスを扱ったり、その独自の強みを活用するアプリケーションを開発したりするために不可欠です。
