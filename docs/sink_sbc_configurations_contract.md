# Public Sink SBC parameter contract

The live public A2dpSinkReceiver supports SBC at 44.1/48 kHz, mono, dual channel, stereo and joint stereo, 4/8/12/16 blocks, 4/8 subbands and loudness/SNR allocation: 128 format combinations. Optional 16/32 kHz and non-SBC codecs are not advertised. This supersedes the old restricted stereo/16-block/8-subband contract for the live implementation, not historical evidence.

Capabilities are `3f ff 02 56`: bitpool envelope 2..86. Negotiation rejects an envelope outside those bounds, an inverted range, an impossible minimum, unknown enum values or inconsistent channel count. Each media frame must match every negotiated format field and its bitpool range. The upper envelope may include pools prohibited for that particular format; each frame independently obeys the syntax ceiling (16×subbands for mono/dual, 32×subbands for stereo/joint) and exact byte-rounded bitrate ceiling (mono 320 kbit/s, two channels 512 kbit/s). There is no rounding down of bitrate before comparison. Dynamic legal bitpool changes within a negotiated range are accepted.

A2DP Appendix B.9 frame size is 4 + subbands×channels/2, plus ceil(blocks×channels×bitpool/8) for mono/dual; stereo/joint instead adds ceil((blocks×bitpool + joint×subbands)/8). Bitrate comparison is frame_bytes×8×rate <= bitrate_limit×blocks×subbands. Maximum admitted frame is 185 bytes (44.1 kHz, joint stereo, 16 blocks, 8 subbands, pool86); fixed storage conservatively reserves 524 bytes, the SBC dual-channel syntax bound, plus 16 decoder prefetch bytes. The reassembler separately owns a 537-byte synthetic RTP packet. All storage is finite; the existing 1024-byte copied packet and 15-frame packet limit remain.

PCM callbacks receive signed 16-bit native-endian packed samples. Mono uses SDK pcmStride=1, stereo/dual/joint use stride2. `frames` always means samples per channel, `blocks×subbands` (16..128), not int16 element count. Consumers read frames×channels elements and return accepted frames, never elements or bytes. RTP timestamp progression is packet frame count×blocks×subbands. Fragment completion advances it once; intermediate fragments do not. Output callback memory is borrowed only for that call. The existing BoundedPcmSink example supports both channels and preserves the format in pull results. Decoder synthesis history is zeroed on configure/recovery; the ordered fragment loss and lifecycle barriers remain.

The internal Config preserves four-field aggregate initialization: appended blocks/subbands/allocation default to16/8/loudness. Public snapshot now reports actual channels and SBC block/subband/allocation/bitpool fields. Allocation is0 loudness,1 SNR; wire channel mode is0 mono,1 dual,2 stereo,3 joint. Unconfigured snapshot values are not negotiated guarantees. Applications that intentionally support only stereo must check channels and return0 for unsupported PCM, not read mono as stereo.

## Raw signaling follow-up and remaining boundaries

The [raw-configuration guard](sink_raw_configuration_contract.md) checks incoming SINGLE_PACKET configurations before parsing/normalization, validates Sink RECONFIGURE and retains codec bytes in stable storage. Use the normal Sink CMake helper to select its hash-pinned generated copy; manual source inclusion does not select it. Composition with the same-peer experimental overlay is unsupported. [Validator rejection recovery](sink_validator_recovery_contract.md) preserves the documented SET rejection lifecycle. Wider signaling lifecycle and signaling fragmentation remain open. Host codec round trips and fragment-equivalence checks do not establish independent reference-vector accuracy, the 14-bit SBC conformance criterion, interoperability across all advertised formats, timing, audio quality or hardware performance.

Sources: [Bluetooth A2DP1.4.1 §§4.3.2–4.3.4 and Appendix B.9](https://www.bluetooth.com/wp-content/uploads/Files/Specification/HTML/a2dp_v1-4-1_1752513648/A2DP_v1.4.1/out/en/index-en.html); installed Pico SDK2.1.1 BTstack501e6d2b86e6c92bfb9c390bcf55709938e25ac1, Bluedroid `decoder/srce/decoder-sbc.c`, `framing-sbc.c`, `synthesis-sbc.c`.
