# 検証範囲と制約

[English](validation.md) · [機能と制約](supported_features_jp.md) · [ドキュメント一覧](documentation_index_jp.md)

実装済みAPI、ソフトウェア・ビルド検査、条件を限定した実機確認を区別して説明します。テスト結果は確認した構成に対するもので、Bluetooth認証やすべての接続相手での動作保証ではありません。

## A2DPの音声

- **Source:** PCMをSBCへ変換して送信する通常の経路には実機確認があります。小さいMTU向けのSBC分割にはソフトウェア・ARMビルドの確認がありますが、実機では未確認です。
- **Sink:** WindowsからのSBC受信とPCMデコードを条件付きで実機確認しています。DAC/I2S出力、音量、バッファ処理はアプリ側で実装します。PCMを数える・破棄するテストは、音が出ることや音質の確認ではありません。
- **コーデック:** 対応するコーデックはSBCです。汎用の符号化済み音声・コーデック・SEP管理APIは未完成です。
- **送受信の同時使用:** 通常のSource/Sink helperが許可するのは別の接続相手に対する所有者です。同じ相手へのSource＋Sinkは明示的に選ぶ実験用機能で、実機の2ストリーム動作としては未検証です。任意段階の取消、再接続、長時間の同時転送は保証しません。

[Sourceの操作](a2dp_source_lifecycle_jp.md)、[PCMの受け渡し](a2dp_sink_pcm_jp.md)、[二つの音声ロール](a2dp_dual_role_jp.md)を参照してください。

## AVRCPの再生操作

ControllerはPicoから相手のプレーヤーを操作する役割、TargetはPicoが受けた操作を自分のアプリで処理する役割です。メタデータ、通知、Browsing、Cover ArtのAPIはありますが、すべての相互接続動作を実機確認したわけではありません。

条件を限定したWindowsとの試験で、**SBCのSink受信中にControllerからNEXT・音量ボタンを送る動作**を確認しています。コマンド応答と実際のプレーヤーの変化を観測しました。別の試験ではPLAY/PAUSEを確認しましたが、終了前の原因未解明の切断も記録されています。長時間安定性、すべてのプレーヤー、絶対音量API、スピーカーの音量、すべてのTarget機能を保証する結果ではありません。

公開サンプル **AvrcpMediaControlSample** と **A2dpSinkPcmConsumer** にはソフトウェア・ビルド検査がありますが、その公開アプリ自体の実機実行は **NOT_RUN（未実行）** です。共通ライブラリの実機結果を、すべてのサンプル構成の実行結果と読み替えないでください。

[Controller](avrcp_controller_jp.md)、[Target API](avrcp_target_jp.md)、[Browsing](avrcp_browsing_jp.md)、[Cover Art](avrcp_cover_art_jp.md)を参照してください。

## SPPのデータ通信

一つの相手への2ルート、再接続、送受信の一時停止・再開、特定の負荷でのデータ一致を条件付きで確認しています。2ルートは独立した2台の無線機や同時に2台の相手へ接続できることを意味しません。共通のBluetoothリンクにはバッファと処理量の制約があり、混在通信時の一般的な速度、遅延、音質の保証はありません。

メッセージの区切り、確認応答、再送方針はアプリ側で決めます。[SPPのライフサイクル](spp_lifecycle_jp.md)、[ポート制御](spp_control_jp.md)、[状態遷移](spp_state_transitions_jp.md)、[実機確認の範囲](spp_hardware_validation_jp.md)を参照してください。

## ボンド保存と追加機能

永続ボンドとcommitted TLVは明示的に有効にする機能です。破損、電源断、回復について限定したソフトウェアモデルとビルド検査がありますが、フラッシュの耐久性、任意の電源断、すべての保存配置を認定するものではありません。デバイスを初期化・運用する前に[ボンドバックエンド](bluetooth_bond_storage_jp.md)と[committed TLVの契約](bluetooth_committed_tlv_jp.md)を確認してください。

HFP/SCO通話音声、BLE、LE Audioは対応範囲外です。[HFPが非対応である理由](HFP_UNSUPPORTED_REASON.md)も参照してください。

## テストとサンプルの読み方

- ホストテストは記載された入力と模擬境界を検査します。無線の相互接続性を証明するものではありません。
- configure・compile・link検査は選択したビルド経路だけを確認します。未使用コードがリンク時に除去される場合もあります。
- 実機結果は実際に使った相手、構成、操作に限定されます。機器の生ログや録音は同梱していません。
- compile probeは完成した実行用アプリではありません。各サンプルの説明を読み、既定の構成から始めてください。
- 長時間動作、接続機器の違い、Wi-Fiとの共存、資源上限、機能の組合せは用途に応じて確認してください。文書の変更を新しいテスト合格と解釈しないでください。

導入と通常の確認は[ビルドガイド](build_guide_jp.md)から始めてください。第三者ソフトウェアにはそれぞれの[ライセンス条件](../THIRD_PARTY_NOTICES.md)が適用されます。
